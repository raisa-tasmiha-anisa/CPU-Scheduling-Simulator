## Project Overview
This repository contains a C-based configurable CPU scheduling simulator developed as part of the Operating Systems sessional coursework. The simulator implements and evaluates five foundational scheduling algorithms:
1. **FCFS** (First-Come, First-Served)
2. **SJF** (Shortest Job First - Non-Preemptive)
3. **SRTF** (Shortest Remaining Time First - Preemptive)
4. **Round Robin (RR)**
5. **Priority Scheduling with Aging**
